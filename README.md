## 📖 About

This repository documents my entire competitive programming journey, starting from the very first day I decided to step into this world. It began because of the motivation, guidance and push I received from the **YouKnowWho** academy.

Every solution and every improvement is stored here as a reminder of **where I started** and **how far I plan to go**.

## 🎯 Goals

- Build strong problem-solving fundamentals, one phase at a time
- Solve problems consistently and keep every solution documented
- Learn core data structures and algorithms through practice
- Track real progress, from the first "Hello World" to harder problems

## 🛠️ Tools & Setup

- **Language:** C++
- **Editor helper:** [CPH (Competitive Programming Helper)](https://github.com/agrawal-d/cph), used for testing against sample cases
- **Compile & run:**

```bash
g++ -std=c++17 solution.cpp -o solution
./solution
```
